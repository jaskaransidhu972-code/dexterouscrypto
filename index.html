About Dexterous Crypto

Dexterous Crypto (DXT) is a founder-led digital token project built on BNB Smart Chain. DXT uses the BEP-20 token standard and has a fixed total supply of 10,000,000 tokens.

The project's current functionality includes token transfers and decentralized trading through PancakeSwap. The smart-contract source code is publicly available for inspection on BscScan.
