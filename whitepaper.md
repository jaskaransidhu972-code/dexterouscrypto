## 1. Project Overview

Dexterous Crypto (DXT) is a digital token deployed on BNB Smart Chain. It uses the BEP-20 token standard and has a fixed total supply of 10,000,000 DXT.

The project currently provides a publicly verifiable token contract, an official website, and a DXT/WBNB liquidity pool on PancakeSwap.

DXT is an early-stage project. Its current functionality includes token ownership, transfers, and decentralized exchange trading.

## 2. Project Purpose

The initial purpose of Dexterous Crypto is to establish a transferable digital token with publicly accessible technical information and decentralized trading infrastructure.

The project aims to communicate clearly about its token supply, contract, available functionality, and future development decisions.

DXT does not currently provide ownership in a company, a claim on project revenue, or guaranteed financial returns.

## 4. Token Supply and Distribution

The DXT contract created 10,000,000 tokens at deployment and assigned the initial supply to the deploying wallet.

The contract does not automatically allocate fixed percentages of the supply to team, marketing, development, or community categories.

Current token holdings and transfers can be inspected through BscScan.

Any future distribution or allocation of project-held tokens should be communicated accurately through the project's official channels.

## 5. Smart Contract

DXT uses an ERC-20-compatible implementation deployed on BNB Smart Chain.

The contract supports standard token functionality, including transfers, balance queries, allowances, and approved transfers.

The contract does not contain a project-specific transfer tax, blacklist, or additional minting function.

The contract source code is publicly available on BscScan.

Source-code verification is not a security audit. No independent professional security audit is claimed in this whitepaper.

## 6. Decentralized Exchange Liquidity

A DXT/WBNB liquidity pool has been created on PancakeSwap V2.

The initial liquidity contribution was approximately 3,625 DXT and 0.005 BNB, using an initial ratio of 725,000 DXT per BNB.

The initial liquidity was relatively small. Even small transactions may therefore cause substantial price impact and slippage.

Liquidity levels, exchange rates, and trading availability may change.

The initial pool ratio is not a guaranteed price or an assessment of the value of DXT.

The project does not claim that liquidity is permanently locked.

## 7. How to Access DXT

Users who choose to interact with DXT can connect a compatible wallet to BNB Smart Chain and access decentralized trading through PancakeSwap.

Before confirming a transaction, users should verify the official contract address and review the token amount, exchange rate, price impact, slippage, network fees, and transaction details.
